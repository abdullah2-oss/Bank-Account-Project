# Bank Account Management System

## Project Description
A simple bank account management system built using Python and Object-Oriented Programming (OOP).

The program allows users to deposit money, withdraw money, and check their current account balance.

## Features
- Initialize a new bank account with a zero balance.
- Deposit money into the account.
- Withdraw money from the account.
- Check the current account balance.
- Display the date and time of each transaction.
- Prevent withdrawals when the balance is insufficient.
- Support premium accounts through class inheritance.

## Concepts Used
- Classes and Objects
- Constructors (`__init__`)
- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- `super()`
- `datetime` Module

## Technologies
- Python 3
- datetime Library
